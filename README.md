## 24.90 澳元这台机器，具体给到什么

参数逐项拆开看：

- **1 核 / 512MB DDR4**：跑 TikTok 网页端、指纹浏览器、少量代理转发够用。512MB 内存是这条产品线的统一配置，别指望在上面同时开几个重负载程序。
- **10GB SSD**：系统加必要环境，剩余空间不多，不适合拿来存素材。
- **100Mbps 带宽 / 2TB 流量**：流量是**双向计费**，上传加下载合计 2TB。发短视频消耗很小，直播推流按码率算，长时间开播要自己盯一下用量。
- **阿联酋原生 IPv4 ×1**：单个独立地址，页面上标的是「原生IPv4」，没有「家宽」二字。

### 「原生 IPv4」和「原生家宽 IPv4」是两档东西

WePC 在每个节点上都会单独标注 IP 类型，对比着看就很清楚：韩国写「韩国原生家宽IP」，英国两个 SKU 写「英国原生家宽IPv4」，马来西亚写「马来原生家宽IP」，阿联酋这一行写的是「阿联酋原生IPv4 x1」。

原生 IP 指的是 IP 注册地和机房所在国一致、ASN 信息真实、IP 库里的历史标记干净。它能过平台的基础归属地校验，不会一上来就被打成 hosting 段。家宽 IP 是从当地 ISP 家庭宽带里出来的地址，在风控模型里更接近真实居民用户，起号和直播的评分通常更好一档。数据中心 IP 则是被明确标记为机房的地址，做核心账号基本没戏。

所以搜「阿联酋原生IP」的人，如果默认自己买到的是住宅宽带地址，下单前要把预期调回来：这台给的是干净的原生机房 IP，不是家宽。做视频发布、账号环境隔离、中东区内容测试，这个档位是合理的；要拿它当住宅 IP 用，方向就错了。
